### Límites de esta evidencia

- La búsqueda estática confirma puntos de entrada y callbacks, pero no demuestra que el servicio/API responda, que el permiso permita la acción ni que el estado posterior se renderice bien.
- Este censo estático ya cubre los destinos principales y varios componentes de operación, pero todavía no identifica todos los campos, validaciones, menús internos ni resultados por rol de las 23 rutas.
- Para cerrar cada registro faltan recorrido con sesión y rol representativos, capturas/observación de estados responsive y ejecución de las pruebas que correspondan. En esta pasada documental no se realizaron mutaciones de datos.

## Auditoría visual base y sistema objetivo

### Lo que ya existe en código

- El tema global `TemaFoody` ofrece claro y oscuro; usa Material 3, Inter para texto de lectura y Poppins para títulos. Los botones principales toman el naranja `ColoresFoody.primario` (`#FF6B35`), el secundario es turquesa (`#2EC4B6`) y existen colores semánticos básicos.
- `SaaSTokens` define superficies, texto, bordes, radios de 8–16 px, espaciado de 4–32 px, sombras y movimiento de 140/180 ms. Hay componentes compartidos para superficies, KPI, tablas, filtros, vacíos, diálogos, formularios y estados asíncronos.
- Estas piezas proporcionan una base real para el rediseño; el trabajo no parte de cero. Sin embargo, existen temas paralelos (ThemeData, `SaaSTokens`, tokens específicos de Analítica, estilos de formularios y colores de operaciones), por lo que el consumo no es todavía uniforme.
- La apariencia clara define un fondo neutro y superficies blancas; la oscura usa canvas `#0B0C0F` y superficie `#16181D`. Eso funciona como tema SaaS oscuro, pero la dirección de referencia requiere distinguir con más claridad navegación azul marino y contenido/superficies. El tema de navegación actual debe revisarse en uso real antes de convertirlo en token global.
- `ColorScheme.fromSeed` y estilos locales coexisten con colores fijos por módulo/gráfico. Esto puede hacer que controles comunes cambien de tono entre pantallas y que el contraste dependa de excepciones locales.
