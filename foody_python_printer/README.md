# foody_python_printer

Servidor **Python** en la red local del restaurante. Recibe órdenes de impresión por WebSocket desde NestJS (`puerto 3001`) e imprime en impresoras térmicas con `python-escpos`.

Flutter **nunca** envía trabajos de impresión.

Implementación: `INFRAESTRUCTURA/GUIA_DESARROLLO_FOODY_CURSOR.md` — Fase 6.
